# minbuild.github.io

minBuild 앱들의 소개·지원·개인정보 처리방침 페이지. <https://minbuild.github.io>

- `app-ads.txt` — AdMob 광고 판매자 확인용. 사이트 맨 위(루트)에 있어야 한다.
- `maldallija/` — 말달리자 - 추억의 택시미터기
- `salary-meter/` — 월급미터기
- `multishort/` — multishort (숏폼 동시 업로드). 소개·지원·개인정보 처리방침·이용약관. 한국어는 `multishort/`, 영어는 `multishort/en/`. 앱의 `TERMS_URL`·`PRIVACY_URL` 이 한국어 주소를 쓰고, 구글 OAuth 동의 화면·메타 앱 설정에도 같은 주소가 들어 있다. 메타의 데이터 삭제 안내는 `privacy.html#delete`.
- `google3d854a95dd89d006.html` — Search Console 소유 확인 파일(구글 OAuth 승인된 도메인). 지우면 확인이 풀린다.
- `one-verse/` — 한 구절 - 성경 (One Verse - BIBLE). 한국어는 `one-verse/`, 다른 언어는 `one-verse/en|es|ja/`에 소개·지원·개인정보 처리방침·이용약관이 있다. 앱의 약관·개인정보 링크(`lib/core/links.dart`)가 이 주소를 쓴다.
